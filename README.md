# 🚀 Space Cleaner

Космическая игра-кликер на Unity!

## 🎮 Как играть
- Кликай по **мусору** (серые круги) → получай очки
- Не кликай по **кристаллам** (фиолетовые квадраты) → теряешь очки  
- У тебя всего **30 секунд**!
